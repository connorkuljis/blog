Useful Shorcuts For Programmers

Bash

Shortcut Description
ctrl + r search backwards through history
$( ) This is called command substitution. It executes the command inside the parentheses and captures its output as a string.

MacOS

Shortcut Description
opt + del delete word backwards

Firefox

Shortcut Description
super + l jump to address bar
