How I Learned Recursion

Mar 23, 2025

204 words

The exercise I used to understand recursion was printing the sequence of n triangular numbers.

Triangular numbers are the sum of all natural numbers up to a certain number.
For example, the 5th triangular number is 1 + 2 + 3 + 4 + 5 = 15.

Here is the code I used to calculate the nth triangular number using recursion:

public class TriangularNumber {
    public static int calculateTriangularNumber(int n) {
        if (n == 1) {
            return 1;
        } else {
            return n + calculateTriangularNumber(n - 1);
        }
    }

    public static void main(String[] args) {
        int n = 5;
        int result = calculateTriangularNumber(n);
        System.out.println("The " + n + "th triangular number is: " + result);
    }
}

When you run this code with n = 5, it will output:

The 5th triangular number is: 15
