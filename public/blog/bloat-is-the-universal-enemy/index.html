Bloat is the Universal Enemy

Mar 23, 2025

69 words

Bloat occurs when the ability to say no is lost.

Here is an example:

  • When a user navigates to a web page in search of a simple cooking recipie,
    the website makes additional requests for worldly ills; ads, trackers,
    javascript pop-ups and the like. None of the things listed prior are
    functional to the purpose of a web page (content and images), nor are they minimal.
