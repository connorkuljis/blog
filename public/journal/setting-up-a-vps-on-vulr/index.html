Setting up a VPS on Vulr

Dec 17, 2024

Setup Vultr Account

  • Create Account on Vultr

  • Add credit card.

    • If your card cannot be added, select a custom amount and add $6.00

  • Create a ssh-key

Create a User with sudo permissions on Debian

  • Add user with sudo permission:
    adduser --ingroup sudo connor

    • type and re-type a user password.

    • when prompted for full name, just keep pressing enter, leave it empty for all fields.

  • You can now login to the user account:
    login connor

Delete User

  • to delete a user:
    sudo userdel username

  • update packages.
    sudo apt update

Install Caddy

  • install caddy
    sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
    curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
    curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list
    sudo apt update
    sudo apt install caddy

Copy Static Content

  • Copy public html to vps:
    scp -r public connor@45.77.171.155:~/kuljis.xyz
